# talleres-pedraza-valdemoro

Propuesta de rediseño **no oficial** para **Talleres Pedraza** (Valdemoro), creada por Alex. Web actual: https://www.tallerespedraza.es/

- **Demo:** https://atilavg.github.io/talleres-pedraza-valdemoro/
- **Concepto:** «Orden de trabajo»: industrial-editorial de taller (hoja de recepción, ficha técnica, muestras de color).
- **Estructura:** `index.html`, `assets/css/`, `assets/js/` (incluye `scroll-intro.js` del _kit), `assets/fonts/` (fuentes OFL alojadas), `.nojekyll`.
- **Intro:** `assets/intro.mp4` avanza con el scroll; sin vídeo se ve una animación propia en canvas. Prompts en `PROMPTS-VIDEO.md`.
- **Aviso:** franja «Propuesta de rediseño no oficial — creada por Alex» y `<meta name="robots" content="noindex, nofollow">`.
- **Docs internos (excluidos con `.gitignore`):** `ANALISIS.md`, `MENSAJES.md`, `crear-repo.ps1`, `capturas/`.
- **Publicar a mano:** `crear-repo.ps1` en PowerShell desde esta carpeta y activar Pages (Settings → Pages → main / root).

Textos e ilustraciones propios; no se usan fotos ni logotipos del negocio.
